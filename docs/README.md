# Zodiac Forest: GDD versions and design reviews

| Folder | What's in it |
|---|---|
| `gdd/zodiac-forest-gdd-v1-original` | The GDD as first submitted for review (25 Nov 2026), before any changes |
| `gdd/zodiac-forest-gdd-final` | The current GDD after both reviews and the owner's decisions (26 Nov 2026) |
| `reviews/round-1/` | First review of the original GDD |
| `reviews/round-2/` | Second review of the revised GDD |

Each GDD comes as Markdown (`.md`) and Word (`.docx`). The GDD's timeline chart doesn't survive export, so it shows as a placeholder.

## How the reviews were run

Both reviews used the [gdd-review-kit](https://github.com/GixGosu/gdd-review-kit):

1. Six reviewers read the GDD in parallel, each working on its own: systems designer, narrative critic, player psychologist, feasibility lead, adversarial QA and business analyst.
2. Each reviewer then read the other five reviews and challenged them. This cross-examination is appended to the end of each reviewer's file.
3. A moderator combined everything into `SYNTHESIS.md`: the top 5 issues, unresolved disagreements, quick wins and a verdict.

Start with `SYNTHESIS.md` in each round.
